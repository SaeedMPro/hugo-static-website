# وب‌سایت MCTN، گروه پژوهشی شبکه‌های کامپیوتری دانشگاه بوعلی سینا (نسخهٔ نمایشی)

سایت ایستا و دوزبانه (فارسی و انگلیسی) ساخته‌شده با [Hugo](https://gohugo.io). نام‌ها و داده‌های این نسخه ساختگی هستند.

صفحه‌ها: خانه، درباره، پژوهش (هر حوزه یک صفحه)، اعضا (هر عضو یک صفحه)، پروژه‌ها، انتشارات، اخبار، رویدادها، آموزش، منابع، پیوستن به گروه، تماس، جستجو و صفحهٔ ۴۰۴.

امکانات:

- تاریخ‌ها در نسخهٔ فارسی شمسی و با ارقام فارسی نمایش داده می‌شوند.
- برای هر مقاله BibTeX ساخته می‌شود و همهٔ انتشارات یک‌جا در `publications/publications.bib` قابل دریافت است.
- تقویم رویدادها (iCal) در `events/index.ics`؛ هر رویداد پیش رو هم فایل جداگانهٔ «افزودن به تقویم» دارد.
- خوراک RSS اخبار در `news/index.xml`.
- جستجو در کل سایت (اعضا، مقاله‌ها، پروژه‌ها، اخبار و رویدادها) بدون سرویس بیرونی.
- حالت تیره، مطابق تنظیم سیستم بازدیدکننده.

## انتشار روی GitHub Pages

1. یک مخزن جدید در GitHub بسازید (مثلاً `netlab-demo`).
2. محتوای این پوشه را در آن push کنید:
   ```bash
   git init
   git add .
   git commit -m "Initial demo"
   git branch -M main
   git remote add origin https://github.com/<USERNAME>/netlab-demo.git
   git push -u origin main
   ```
3. در مخزن به **Settings ← Pages** بروید و در بخش **Build and deployment** گزینهٔ **Source** را روی **GitHub Actions** بگذارید.
4. در تب **Actions** صبر کنید تا اجرای «Deploy Hugo site to Pages» سبز شود. سایت روی `https://<USERNAME>.github.io/netlab-demo/` در دسترس است.

از این به بعد هر push به شاخهٔ `main` سایت را دوباره می‌سازد و منتشر می‌کند. سایت هر شب هم یک بار خودکار ساخته می‌شود تا رویدادهای گذشته از فهرست «پیش رو» بیرون بروند.

## اجرای محلی

[Hugo Extended](https://gohugo.io/installation/) نسخهٔ 0.139.0 یا بالاتر را نصب کنید، سپس:

```bash
hugo server
```

سایت روی `http://localhost:1313/netlab-demo/` باز می‌شود (نسخهٔ انگلیسی روی `/netlab-demo/en/`).

## افزودن و ویرایش محتوا

همهٔ داده‌ها دوزبانه‌اند: هر متن یک نسخهٔ `_fa` و یک نسخهٔ `_en` دارد. سال‌ها شمسی نوشته می‌شوند (مثلاً `"1403"`) و در نسخهٔ انگلیسی خودکار میلادی می‌شوند.

| کار | فایل |
| --- | --- |
| عضو جدید | یکی از فایل‌های `data/people/` را کپی کنید، نام فایل را شناسهٔ انگلیسی عضو بگذارید و فیلدها را پر کنید. `areas` حوزه‌های پژوهشی و `advisors` استاد(ان) راهنمای اوست |
| عکس عضو | فایل عکس را در `static/people/` بگذارید (مثلاً `karimi.jpg`، مربعی و حدود ۴۰۰×۴۰۰ پیکسل) و در فایل عضو بنویسید `photo: "people/karimi.jpg"`. بدون عکس، حروف اول نام نمایش داده می‌شود |
| رزومهٔ عضو | فایل PDF را در `static/cv/` بگذارید و در فایل عضو بنویسید `cv: "cv/karimi.pdf"` |
| فارغ‌التحصیلی عضو | در فایل همان عضو `status: alumni` بگذارید و `end_year` و `position_fa`/`position_en` را پر کنید. اگر سال میلادی با «سال شمسی + ۶۲۱» فرق دارد، `end_year_en` را هم بنویسید |
| مقاله | یک مورد به `data/publications.yaml` اضافه کنید؛ در `authors` شناسهٔ اعضای گروه را بنویسید تا به صفحهٔ آن‌ها پیوند بخورد و در `areas` حوزه‌ها را. BibTeX خودکار ساخته می‌شود |
| پروژه | یک فایل در `data/projects/` (اعضا، حوزه‌ها، مقاله‌ها و پیوند کد) |
| حوزهٔ پژوهشی | یک فایل در `data/areas/` |
| رویداد (سمینار، دفاع، کارگاه) | یک فایل در `data/events/` با `date` و در صورت نیاز `time` به وقت تهران (مثلاً `"14:00–15:30"`) |
| درس | یک مورد در `data/courses.yaml` |
| کد، داده و راهنما | یک مورد در `data/resources.yaml` |
| خبر | یک فایل Markdown در `content/fa/news/` و همان خبر در `content/en/news/` با `translationKey` یکسان |
| صفحه‌های درباره، پیوستن و تماس | `content/fa/about.md`، `join.md`، `contact.md` و نسخه‌های انگلیسی در `content/en/`؛ بخش‌ها (واقعیت‌ها، آزمایشگاه‌ها، موضوعات آزاد، پرسش‌ها و …) در بالای همین فایل‌ها هستند |
| ایمیل، تلفن، نشانی، زمان سمینار هفتگی | `hugo.toml` (بخش `params` و `languages.*.params`) |
| منوی بالای صفحه | فهرست `nav` در `hugo.toml` |
| متن‌های رابط کاربری | `i18n/fa.toml` و `i18n/en.toml` |

برای حذف نوار «نسخهٔ نمایشی»، در `hugo.toml` مقدار `demo` را `false` کنید.

## ساختار

```
data/            داده‌های اعضا، حوزه‌ها، پروژه‌ها، انتشارات، رویدادها، درس‌ها و منابع
content/fa, en   صفحه‌ها و اخبار هر زبان
layouts/         قالب‌ها؛ اجزای مشترک در layouts/partials
assets/css/      main.css (رنگ‌ها، حروف و اجزای مشترک) و sections/ (استایل هر بخش)
assets/js/       رفتارهای صفحه (پالایه‌ها، BibTeX، جستجو)
static/          فونت وزیرمتن (مجوز SIL OFL)، آیکون سایت، عکس‌ها و رزومه‌ها
design/          طرح صفحه‌ها (فارسی و انگلیسی) که سایت از روی آن‌ها ساخته شده است
```
